================================================================================
GUIA DE ADMINISTRACION: SISTEMA DE PURGA (PurgaPlugin)
================================================================================

--------------------------------------------------------------------------------
1. PERMISOS DEL PLUGIN (LuckPerms u otro gestor de rangos)
--------------------------------------------------------------------------------
- purga.admin
  Acceso total a todos los comandos de la purga (iniciar, detener, status, reload).
  Por defecto asignado a OPs.

- purga.bypass.commands
  Permite a los administradores y staff usar comandos bloqueados (/spawn, /tpa, /home)
  incluso durante el evento de purga.


--------------------------------------------------------------------------------
2. COMANDOS ADMINISTRATIVOS
--------------------------------------------------------------------------------
Todos los comandos cuentan con autocompletado con la tecla TAB.

* INICIAR PURGA:
  /purga start [tiempo]   (o /purga on [tiempo])

  Ejemplos de tiempo admitidos:
  - /purga start          -> Inicia con la duracion por defecto de config.yml (30m).
  - /purga start 30s      -> Dura 30 segundos (ideal para pruebas).
  - /purga start 15m      -> Dura 15 minutos.
  - /purga start 2h       -> Dura 2 horas.
  - /purga start 24h      -> Dura 24 horas (1 dia).
  - /purga start 3d       -> Dura 3 dias.
  - /purga start 1h30m    -> Dura 1 hora y 30 minutos (combinacion libre).
  - /purga start manual   -> Modo indefinido (dura hasta que uses /purga stop).

* DETENER PURGA:
  /purga stop             (o /purga off)
  Finaliza el evento inmediatamente, limpia los mobs asesinos restantes,
  retira la BossBar y envia el reporte a Discord.

* ESTADO Y ESTADISTICAS:
  /purga status
  Muestra si el evento esta activo, el tiempo restante y las bajas cobradas.

* RECARGAR CONFIGURACION:
  /purga reload
  Aplica cualquier cambio de config.yml al instante sin reiniciar el servidor.
